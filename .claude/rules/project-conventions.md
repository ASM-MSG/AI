# Project Conventions

FillMap-AI(파이썬 단일 코드베이스) 코딩 컨벤션. 모든 변경에 강제 적용.

## 파이썬 코딩 스타일

**들여쓰기는 하드탭이다.** PEP 8은 스페이스 4칸이지만, 이 레포는 `bench.py`·`server.py`
전부 탭으로 쓰였고 **레포 관행이 정본**이다 — 새 파일도 탭으로 쓴다. 한 파일 안에서 탭·스페이스를
섞지 않는다(파이썬은 이걸 문법 에러로 잡는다).

- 최대 줄 길이: 120자
- 함수·변수·모듈: `snake_case` / 클래스: `PascalCase`
- 상수는 **파일 상단에 모아 `SCREAMING_SNAKE_CASE`** — 값의 근거(실측 티켓·리포트 경로)를
  주석으로 붙인다. 선례: `bench.py`의 `PLATE_MODEL`, `FACE_CONF`
- import 순서: 표준 라이브러리 → 서드파티 → 로컬(`import bench`), 그룹 간 빈 줄 하나

## 주석 · docstring

**한국어로 쓴다.** 무엇을 하는지가 아니라 **왜 그런지**를 남긴다 (`bench.py`의 가중치 파일명
주석이 표준 — "추측하면 조용히 large를 집는다"처럼 함정을 적는다).

**파일 상단 docstring에 실행법을 명기한다.** 티켓 번호로 시작해 목적 → 실행 명령 →
환경변수 노브 순서. 예: `server.py` 상단.

```python
"""MSG-XXX — 한 줄 목적.

왜 이렇게 만들었는지 1~3줄. 결정 근거 문서 경로가 있으면 함께.

    python xxx.py --smoke        # 자기검증
    python xxx.py sample.mp4 --device cpu
"""
```

- 티켓 번호(`MSG-XXX`)를 근거 표시에 쓴다 — 실측 수치·정책 결정에는 항상 `results/MSG-XXX-report.md`
  같은 근거 경로를 병기한다.
- 의도적으로 자른 코너(단일 워커, 인메모리 저장소 등)는 `# ponytail:` 주석으로 한계와
  업그레이드 경로를 남긴다 (`server.py`의 잡 저장소 주석이 선례).

## 검증 관행 — 테스트 프레임워크 없음

이 레포에는 pytest 같은 프레임워크가 없다. 검증은 세 층으로 한다:

1. **`--smoke` 셀프체크 (필수)** — 로직을 추가하면 그 파일의 `--smoke` 경로가 그것을 실제로
   태우게 만든다. `bench.py --smoke`는 합성 영상으로 파이프라인을, `server.py --smoke`는
   httpx TestClient로 API 왕복을 검증한다. **새 검증 경로가 필요하면 프레임워크를 도입하지 말고
   기존 `--smoke`를 확장한다.**
2. **실측 리포트** — 성능·정확도 주장은 `results/MSG-XXX-report.md` + 원자료 JSON으로 남긴다.
   숫자 없는 "빨라졌다"는 완료 근거가 아니다.
3. **EC2 실측만 유효** — 성능·리소스 수치는 dev EC2(`scripts/ec2-bench.sh`)에서만 잰다.
   **macOS 실측은 무효다** (Apple Silicon PyTorch가 스레드 설정을 무시 — CLAUDE.md "알아둘 함정" 절).

기능 정확도(블러 누락 등)는 **recall 우선**으로 판단한다 — 과블러는 손해가 작지만 미탐지는
프라이버시 사고다.

## 의존성 추가

**새 의존성은 라이선스를 먼저 확인한다.** 이 레포는 AGPL-3.0이고 BE는 MIT를 유지해야 한다 —
AGPL/GPL 의존성은 여기서 OK지만 BE로 새어나가면 안 된다 (CLAUDE.md "라이선스 — 절대 규칙" 절).
추가한 의존성은 `requirements.txt`에 고정하고, 이미지 크기·설치 시간 증가가 이득에 비해
큰지 판단한다 (MSG-207에서 OpenVINO를 +5% 이득에 ~100MB라서 기각한 선례).

## 커밋 · 브랜치

**CLAUDE.md "브랜치 · 커밋" 절이 단일 정본이다** — 여기서 중복 서술하지 않는다.
요약만: `feature/MSG-{번호}-{설명}` 브랜치, `MSG-{번호} {타입}: {요약}` 커밋, 커밋은 사용자가 직접.
